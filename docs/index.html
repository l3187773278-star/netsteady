netsteady

跨境链路稳定性监测 + 出口 IP 纯净度体检。零依赖，纯标准库，Python 3.9+。

安装

git clone https://github.com/l3187773278-star/netsteady.git
cd netsteady
python -m netsteady --help

watch

跨境链路稳不稳

TCP 握手探测，境内对照组做基线，丢包 / P95 / P99 / 抖动 / 断流，按小时分桶看晚高峰。

python -m netsteady watch \
  -d 10m --html report.html

ip

出口 IP 干不干净

多源地理一致性、机房/代理特征、DNS 出口、黑名单；再加上 14 个限华 AI 服务的逐个探测：解析 IP、IP 属地、握手耗时、是硬挡还是 WAF 质询。

python -m netsteady ip

leak

它们能不能看穿你

IPv6、UDP/STUN、DNS 出口、时区语言、CDN 接入点——五条绕过代理的通道逐条检查，命中给出处置建议。地址不同不等于泄漏，比对归属地之后再下结论。

python -m netsteady leak
